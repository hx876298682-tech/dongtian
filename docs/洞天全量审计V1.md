# 《洞天》全量审计 V1

## 执行入口

```bash
ruby docs/洞天全量审计V1.rb
```

入口按文件名顺序串行执行所有 `验证*.rb` 脚本，然后运行 `demo/scripts/audit-release-inputs.mjs`。两个阶段都只读取参数表、Node 生成物和 content 包；不会重建或写回任何文件。任何一个验证器失败都会终止审计并返回非零状态，避免把半成品参数表或局部绿灯当成完整通过。

## 当前覆盖

- 参数表 12 列、唯一 ID、状态枚举和空值规则。
- 成长、建筑、资源、突破、战斗、地图、装备、功法、法宝、秘境、Boss、离线、长期经济、保底、持久化和高阶供给。
- 固定种子状态边界、期望值供需锚点和逐秒 Boss/玩家生存样例。
- Node 生成物与权威 CSV 的版本、行数、SHA-256、参数 payload 漂移。
- content manifest 的 config version、参数 hash、content hash、schema 和 `content_pending` 可达性。
- `full_v1` 六境界战斗 contract 的结构校验及正式 provenance（含 mode selector）。

当前入口验证的是 V1 设计一致性，不会把 `proposal_v1` 自动升级为最终定案；最终参数冻结仍需要随机统计置信区间、实际战斗配置和产品验收。
