# 《洞天》项目结构与维护边界 V1

## 当前权威入口

后续开发、代码评审和 UI 联调按以下顺序读取：

1. `洞天当前运行时口径V1.md`：当前行动序列、灵田和自动入库规则。
2. `洞天_Web版API与数据库详细契约V1.0.md`：服务端 DTO、CAS、幂等和迁移边界。
3. `洞天_Web版核心玩法数据结构设计V1.0.md`、`洞天_Web版首发内容规格V1.0.md`：内容对象和状态字段。
4. `demo/src/server`、`demo/src/content`：运行时实现和内容配置。
5. `洞天数值参数表.csv`、`洞天数值版本V1.md`：唯一冻结数值来源。

## 目录边界

- `demo/src/game`：纯游戏计算和冻结参数映射。
- `demo/src/server`：服务端领域逻辑、HTTP 路由、仓储和迁移。
- `demo/src/content`：首发内容配置和 manifest。
- `demo/scripts`：配置生成、发布审计和候选输入校验。
- `docs/验证*.rb`：全量 Ruby 审计链使用的验证器，不能随意删除或改名。
- `docs/工作记录.md`、`demo/WORK_LOG.md`：持续工作记录，每次任务结束必须追加。
- `../洞天-archive-20260827`：历史研究和旧原型的可恢复归档，不属于当前 runtime 输入。

## 维护规则

- 归档文档不能驱动 API、数据库、参数表、内容 manifest 或 UI 行为。
- 新增玩法先更新当前运行时口径和 API/数据契约，再实现代码和测试。
- `proposal_v1` 只能作为待审批输入；未完成 provenance、平衡证据和迁移语义前保持 fail-closed。
- 不把 `demo/dist`、`demo/node_modules`、`.DS_Store` 或临时输出纳入源代码交付。
- 变更冻结参数时必须同步 manifest、release audit、Ruby 审计和工作记录。
