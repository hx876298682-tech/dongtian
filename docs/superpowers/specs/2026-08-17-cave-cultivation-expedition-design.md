# 洞府、修炼与历练职责重构

## 产品职责

- 洞府：修建和升级练功房、炼丹炉、锻造炉；展示等级、成本、耗时、库存缺口和效率增益。
- 修炼：选择练气、练体、练剑、练刀等修行方向，并启动对应挂机行动；突破作为修炼下的独立子入口。
- 历练：先选择地图区域，再选择区域内怪物；展示怪物战力、属性、可能掉落和对应秘境入口。

## 真实性边界

- 现有洞府设施 API 已支持聚灵室、炼丹房、炼器房的建造升级；前端展示名调整为练功房、炼丹炉、锻造炉，不改服务端 ID。
- 当前行动配置只有 `action.cultivation.qi`。练气可执行；练体、练剑、练刀展示为尚未配置，不伪造修为速率或队列 action。
- 当前后端可执行秘境为青蛇洞、玄铁洞窟、黑风秘境，分别覆盖六只可选择怪物；区域中其余怪物可以展示真实属性与掉落，但明确标记尚无可进入秘境。

## 路由与导航

- 左侧“洞府”直接指向 `/dashboard/cave`；`/dashboard` 重定向到洞府设施。
- 原闭关队列工作台移动到 `/dashboard/queue`，顶部行动进度跳转到该地址。
- `/cultivation` 为修炼方向选择页；`/cultivation/breakthrough` 保留原突破页。
- `/expedition` 为地图与怪物选择；进入可执行怪物后复用现有秘境预览、进入、路线选择与结算流程。

## 验收

1. 点击洞府首先看到练功房、炼丹炉、锻造炉及其升级成本和效果。
2. 修炼页展示四个方向，练气可开始无限挂机，未配置方向不可执行且原因明确。
3. 历练页展示六个区域、区域怪物、怪物属性与掉落；支持三套现有秘境的怪物选择与进入。
4. 不出现原始 `realm.*`、`monster.*`、`loot.*` 键作为主要玩家文案。
5. 相关测试、Web 全量测试、typecheck、lint、build 和 `git diff --check` 通过。
