# 全页面单屏布局设计

## 目标

在 960×600 主视口下，所有核心页面一次展示完整工作区，不要求用户滚动页面寻找主操作。页面内容按信息优先级压缩，右侧空白区域用于并列列表、状态和详情。

## 统一规则

- `shell-main__content` 不承担页面滚动；页面根布局使用 `height: 100%`、`min-height: 0` 和 CSS Grid/Flex 收纳内容。
- 顶部摘要最多占一行，主要操作和状态必须留在首屏。
- 多条同类信息用 2-4 列网格，卡片缩短内边距、正文截断到 1-2 行，避免纵向堆叠。
- 只有真正的次级弹窗内容允许在弹窗内部滚动；主页面不出现纵向滚动条。
- 960×600 为基准，同时保持 760px 以下单列紧凑布局，不让固定宽度造成横向溢出。

## 页面策略

- 行为页/炼丹/炼器：顶部摘要 + 左侧区域/分类网格 + 右侧资源/配方三列网格。
- 修炼：顶部摘要 + 方向选择网格 + 武器专精网格，突破入口作为紧凑状态条。
- 历练：顶部目录两行区域网格 + 怪物三列网格；秘境准备与运行状态并排。
- 洞府/背包/装备：状态摘要、设施/装备/材料使用 CSS 子网格并列；详情保持紧凑，不重复纵向标题。
- 闭关队列/百艺总览：高级设置和预览并列，主列表使用有限行高与密集卡片。

## 验收

1. 960×600 下核心路由的 `document.documentElement.scrollHeight === innerHeight`，`.shell-main__content.scrollHeight <= clientHeight + 1`。
2. 主操作、当前状态和核心列表均在首屏可见；不通过 `overflow-y: auto` 隐藏主页面内容。
3. 760px 以下只保留必要的内部弹窗/抽屉滚动，不出现横向溢出。
