# 百艺行为执行设计

## 目标

让玩家从左侧“百艺”进入独立的采药行为页，先选择地图区域，再选择区域内资源，点击后立即开始对应挂机行为；顶部全局进度栏继续显示服务端队列的实时进度。

## 交互结构

- 左侧导航在“百艺”下增加“采集”子入口，当前第一版默认进入 `/craft/herbalism`。
- 采药页由三段组成：区域列表、区域资源列表、当前选择与开始反馈。
- 区域来自 `config/releases/2026.08.16.1/regions.json` 的已知配置映射；页面只展示有采药行动的区域。
- 区域锁定状态依据行动目录的 `unlocked` 与 `unlock_state.reason`，不在前端推断境界。
- 资源卡展示资源名称、产出、耗时、技能经验和可用/锁定状态；点击“开始采集”直接调用与首页快捷任务相同的队列保存语义：单行动、无限模式、保存后自动恢复暂停队列。
- 行为触发成功后保留当前页，并通过全局进度栏和统一 Toast 反馈；不要求玩家跳转首页查看进度。
- 没有对应行动目录、区域配置或接口失败时显示真实空态/错误态，不伪造可执行状态。

## 数据与边界

- 不新增行为结算逻辑，不绕过 API，不复制一套前端进度计时器。
- 使用现有 `apiClient.getActions()`、`apiClient.getQueue()` 和 `apiClient.saveQueue()`；顶部进度仍由 `GlobalIdleProgress` 读取队列。
- 区域配置先在 Web 适配层建立小型静态映射，字段只包含区域 id、展示名、描述、阶段、采药行动 id 与资源 id；行动详情和解锁权威来自 API。
- 未来挖矿、采集其他类别可复用同一映射与卡片组件，本次不扩展为新的后端领域模型。

## 验收标准

1. 左侧百艺区域可看到“采集 / 采药”子菜单，点击可进入 `/craft/herbalism`。
2. 采药页能显示至少百草谷、雾隐坡、灵泉谷、筑基药园等已配置区域；区域切换会更新资源卡。
3. 选择已解锁资源并点击开始后，调用队列保存接口，暂停队列会自动恢复，顶部进度栏显示该行动。
4. 锁定资源明确显示解锁原因且不可点击；接口错误和无匹配内容有可理解空态。
5. 新增页面/适配器测试通过，Web typecheck、lint、构建通过。
