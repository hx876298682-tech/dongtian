# 单人挂机页面简化设计

## 目标

除市场、宗门、社交、排行榜和付费兑换等联网玩法外，左侧主导航只保留已经形成单人闭环的页面。每个可挂机页面统一为：进入页面、选择区域或分类、点击资源/怪物/配方开始无限挂机、在全局行为栏查看进度。

## 交互基线

- 修炼：直接展示修炼方向，点击一次开始挂机。
- 采药 / 挖矿：先选区域，再点击资源卡开始挂机。
- 炼丹 / 炼器：先选配方分类，再点击配方开始挂机。
- 历练：先选地图，再点击怪物卡立即开始无限战斗挂机；不要求玩家先配置策略、路线或重复确认。
- 洞府：只展示设施、升级成本和升级动作，不承载任务入口。
- 角色 / 背包：只承担装备、工具和物品管理，不引入行动队列编辑。
- 突破：达到门槛后提供单一主动作；复杂路线作为后续可选内容，不阻塞单人挂机主链。

## 导航边界

- 主导航保留：洞府、修炼、百艺、历练、角色、背包、设置、指南、规则。
- 联网玩法保留锁定入口：市场、宗门、仙友、修行榜；明确标注联网玩法暂未开放。
- 从主导航移除没有完成闭环的占位入口：商店、牛铃商店、任务、迷宫、成就、新闻、更新日志。已有直达路由暂时保留，避免旧链接失效。

## 成长与权限

- 炼气小境界随修为自动推进，筑基及以上仍必须走突破。
- 教程只负责解释，不作为功能权限门槛；没有教程存档时也不能永久锁死采药和炼丹。
- 所有挂机页面从同一份配置读取行动耗时、名称和产出，全局进度不得再维护硬编码副本。

## 验收

- 新角色能够开始修炼，修为达到阈值后自然解锁采药、炼丹、挖矿和历练。
- 历练页只需地图和怪物两次选择；点击可用怪物即写入一个无限行动并开始结算。
- 每个资源、配方和怪物卡都有明确耗时、收益、门槛和单一开始动作。
- 联网页面不伪装成可玩的本地系统。
- 单元测试、类型检查、真实浏览器纵向流程通过。
