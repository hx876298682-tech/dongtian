# 武器专精修炼设计

## 目标

在修炼页增加武器专精分区。玩家可以修炼剑、刀、枪、杖等武器专精；专精通过独立的无限修炼行动获得技能经验和等级；角色装备带有对应武器标签的武器后，专精等级会转化为战斗攻击加成。

## 数据链路

1. `skills.json` 增加武器专精技能，技能标签包含 `weapon_mastery` 和武器类型，配置每级攻击加成比例。
2. `actions.json` 增加对应专精修炼行动，行动 `skill_id` 指向专精技能，结算沿用现有技能 XP 逻辑。
3. 修炼页从行动目录动态展示专精卡片，只有服务端返回且支持 `INFINITE` 的行动可启动。
4. 历练战斗构建玩家快照时读取已装备武器的 item tags，匹配对应专精技能等级；只对武器攻击贡献应用配置的每级加成。

## 初始数值

- 剑、刀、枪、杖四个专精都从凡人入门开放。
- 专精行动每轮 60 秒，奖励 5 点对应技能 XP，不产生物品和修为 XP。
- 每级专精对匹配武器攻击提供 2% 加成；不同武器只匹配自己的专精，未匹配时不加成。
- 当前发布装备只有剑类武器，因此剑专精可以立即影响历练战斗；其他专精先提供完整修炼链路，待对应武器配置加入后自动生效。

## 验收标准

1. 修炼页有“武器专精”分区和四张专精卡，能启动真实专精行动并显示技能 XP/等级。
2. 专精行动写入现有无限队列，顶部进度栏和技能等级刷新。
3. 装备剑类武器且剑专精等级大于 0 时，历练玩家战斗快照的攻击和战力提高；装备未匹配武器或专精为 0 时保持原值。
4. 配置加载、内容 API、技能结算、战斗快照均有测试；Web/API/规则包门禁通过。
