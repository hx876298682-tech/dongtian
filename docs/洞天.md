# 《洞天》游戏设计文档（GDD）V1.0

## 一、游戏概述

### 游戏名称

《洞天》

### 类型

东方修仙深度放置 RPG。

核心参考： - 梅尔沃放置：自由成长、挂机生产循环 -
暗黑类游戏：装备掉落与成长追求 - 修仙题材：境界、功法、洞府、法宝

### 核心定位

玩家扮演一名修士，拥有自己的洞天，通过闭关修炼、资源生产、炼丹炼器、探索大陆、收集功法法宝，不断突破境界。

核心体验：

> 经营自己的洞天，走出属于自己的修仙道路。

     ↓

     ↓
    升级洞天
     ↓

# 三、世界观

## 单一修仙大陆

玩家所在世界：

-   青云域
-   南荒
-   北境
-   上古禁地

玩家从凡人开始，通过修炼最终飞升。

第一阶段目标：

凡人 → 炼气 → 筑基 → 金丹

后续扩展：

元婴、化神、炼虚、合体、大乘、渡劫、飞升。

------------------------------------------------------------------------

# 四、玩家核心身份

玩家不是固定职业。

所有玩家：

-   同一起点
-   无灵根差异
-   无职业限制

玩家通过长期投入形成自己的道路。

例如：

## 剑修路线

投入： - 剑类功法 - 飞剑装备 - 战斗资源

成为剑道高手。

## 丹修路线

投入： - 炼丹 - 丹方收藏 - 洞府丹房

成为丹道大师。

## 器修路线

投入： - 炼器 - 装备打造

成为炼器宗师。

------------------------------------------------------------------------

# 五、洞天系统

## 定位

玩家私人修仙基地。

首页即为自己的洞天。

------------------------------------------------------------------------

## 建筑

### 练功房

作用： - 修炼功法 - 获得修为

升级提升： - 修炼速度 - 闭关效率

### 炼丹房

作用： - 炼制丹药

影响： - 炼丹速度 - 丹药品质

### 炼器房

作用： - 打造装备 - 强化装备

### 灵田

作用： - 自动生产灵药

### 功法阁

作用： - 收藏功法 - 提升功法研究能力

### 法宝阁

作用： - 收藏法宝 - 提供永久属性

------------------------------------------------------------------------

# 六、境界系统

采用：

大境界 + 小境界。

结构：

炼气： - 一层至九层 - 圆满

筑基： - 初期 - 中期 - 后期 - 圆满

金丹： - 初期 - 中期 - 后期 - 圆满

------------------------------------------------------------------------

# 七、成长节奏

目标：

前快后慢。

规划：

第一天： 炼气圆满。

第二天： 筑基。

一周： 金丹圆满。

之后：

金丹→元婴： 数周。

更高境界： 月级成长。

------------------------------------------------------------------------

# 八、修为系统

采用：

主修炼 + 外部辅助。

## 修为来源

主要：

练功房。

辅助：

-   丹药
-   功法
-   洞天等级

------------------------------------------------------------------------

## 突破条件

突破需要：

-   修为
-   丹药
-   灵石
-   特殊材料

突破不是单纯升级。

------------------------------------------------------------------------

# 九、功法系统

定位：

# 十八、设计原则

1.  不限制玩家路线。
2.  不加入开局随机天赋。
3.  不强制每日上线。
4.  高频玩家效率更高，低频玩家也能成长。
5.  前期简单爽，中后期深度成长。
6.  系统逐步开放，避免复杂度过早爆炸。
