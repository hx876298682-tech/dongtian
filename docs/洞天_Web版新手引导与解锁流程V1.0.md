# 《洞天》Web版新手引导与解锁流程 V1.0

## 设计目标

新玩家在不阅读外部说明的情况下，完成“选择主动序列 -> 等待/结算 -> 种植灵田 -> 进入战斗 -> 获得成长 -> 突破”的首轮闭环。引导只解释操作和反馈，不改变 `1.0.0-frozen` 的数值。

当前运行时规则：炼气、战斗、炼丹、炼器、功法研究和法宝研究共用一个主动序列；启动新序列会先结算旧序列。炼丹/炼器完成批次自动入库，不显示“领取生产收益”按钮。灵田种植不占主动序列，成熟后自动入库。

## 解锁原则

- 解锁以境界、首次操作和内容任务为条件；不额外增加隐藏战力或资源门槛。
- 已解锁内容永久保留，切换境界不回收。
- 数值不足的突破仍遵循冻结规则：材料不齐不扣除、不耗时；材料齐全必定成功。
- 高阶远征资源供给和高阶 Boss 独立奖励分开处理：资源窗口可运行，Boss 奖励仍受 `collected_p10` 入口门槛。

## 解锁表

| 节点 | 解锁内容 | 触发条件 | 玩家必须理解 |
| --- | --- | --- | --- |
| 首次进入 | 洞天首页、练功房、灵田、炼丹房、百草谷、基础配方 | 创建角色完成 | 主动序列与灵田种植的区别 |
| 完成首次闭关 | 修为进度、离线结算入口 | 首次完成离线结算 | 收益按服务器时间结算并自动入库 |
| 首次完成百草谷 | 背包、装备实例、地图掉落 | 百草谷成功一场 | 失败不发奖励，装备进入仓库 |
| 进入筑基 | 炼器房、黑风谷、功法阁、清风秘境 | `realm_id=foundation` | 装备成长和功法研究使用不同资源 |
| 进入金丹 | 法宝阁、赤炎洞、炎狱秘境 | `realm_id=core` | 高收益活动会竞争丹药和库存 |
| 进入元婴 | 天渊秘境、高阶资源远征入口、扩展法宝池 | `realm_id=nascent_soul` | 高阶资源供给与 Boss 奖励门槛不同 |
| 达到 P10 构筑 | 高阶 Boss 独立奖励 | `entry_gate.profile=collected_p10` | 门槛外失败不扣丹药、不发独立掉落、不推进 Boss 保底 |
| 后续高阶境界 | 当前境界扩展法宝池和专属 Boss 技能 | 进入对应 realm | 每个高阶境界有 10 个小境界 |

## 首次进入流程

```text
创建角色
 -> 展示洞天首页和当前修为
 -> 自动选中练功房主行动
 -> 引导种植灵田并查看成熟时间
 -> 引导查看炼丹序列入口
 -> 提示百草谷可进入
 -> 玩家完成一场百草谷
 -> 展示装备、资源和下一步推荐
```

首次进入不弹出长教程；每一步只展示一个可执行动作。玩家关闭提示后，入口保留在对应页面的状态提示中。

## 首日流程

### 阶段 A：建立生产循环

玩家完成第一段练功结算，种植灵田，再启动炼丹序列。页面必须展示：当前序列、预计完成时间、资源消耗、自动入库产出、灵田成熟时间和库存上限。

### 阶段 B：完成第一场战斗

引导玩家选择百草谷，进入战斗准备页，确认装备、功法和丹药，再启动主行动。战斗结算必须展示成功/失败、耗时、资源、装备品质和古修残卷保底进度。

### 阶段 C：第一次成长

玩家从背包进入装备详情，完成一次不需要失败概率的强化或装备替换；系统展示战力变化，但同时提示战力只是展示值，地图实际结果由战斗属性决定。

### 阶段 D：准备突破

当修为或材料接近突破条件时，展示突破清单、缺口来源和预计获得路径。材料不足时按钮保持可查看但不可提交，不消耗资源。

## 第二天到首周流程

| 时间节点 | 推荐目标 | 系统提示 |
| --- | --- | --- |
| 24h | 炼气目标完成 | 完成结算，检查突破清单 |
| 48h | 进入筑基 | 解锁炼器房、黑风谷、功法阁、清风秘境 |
| 72h | 形成装备/功法成长循环 | 引导研究功法层数和装备出口 |
| 168h | 金丹目标完成 | 解锁法宝阁、赤炎洞、炎狱秘境，提示丹药压力 |
| 首周后 | 选择长期路线 | 展示 `qing_90d_then_black` 路线和 `retain_rare` 出口策略 |

这些时间点来自 GDD 和冻结成长目标；系统不得用奖励加速把目标提前改写成另一条数值曲线。

## 引导状态机

```text
not_started
 -> welcome_seen
 -> training_started
 -> first_settlement_claimed
 -> first_map_started
 -> first_map_completed
 -> first_equipment_reviewed
 -> breakthrough_previewed
 -> onboarding_completed
```

每个节点保存 `tutorial_step_id` 和 `completed_at`。重复登录只检查未完成节点，不重复发奖励。引导完成状态与玩家资源事务分离，重复请求不得产生资源。

## 失败与纠偏提示

- 丹药不足：显示缺口、炼丹序列产能、库存和可替代地图；不自动替换玩家序列。
- 战斗死亡：显示死亡时间点、受到伤害来源、已完成场次和恢复冷却；不展示虚构的失败掉落。
- 高阶门槛不足：显示攻击/防御/生命缺口和 P10 收集进度；说明资源供给仍会运行。
- 仓库满载：显示保留的进阶重复件、自动分解/出售结果和溢出数量。
- 离线结算被拒绝：显示原因（时间回拨、重叠区间、过期 revision 或重复结算），不提供“再次领取”造成重复收益。

## 引导验收

1. 新玩家不操作帮助文档也能完成一次练功、一次百草谷、一次装备查看和一次突破预览。
2. 引导只改变界面提示和内容可见性，不改变冻结参数、掉落、奖励或结算时间。
3. 任何引导 API 都具备幂等键；重复点击不重复发奖。
4. 24/48/168 小时目标仍由冻结参数验证器复算，不由引导脚本单独计算。
5. 高阶门槛、失败和仓库溢出提示与战斗/经济结算摘要一致。
