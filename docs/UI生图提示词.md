# 《洞天》统一 UI 生图提示词

## 使用方式

每次生图都按以下顺序拼接：

1. 统一母提示词
2. 对应页面提示词
3. 统一负面提示词

第一张建议先生成“历练页”，选中满意结果后，后续页面都把它作为风格参考图，并使用相同模型、尺寸、seed、风格化强度和配色。不要让模型每一页重新设计导航与顶部状态栏。

## 统一母提示词

```text
为东方修仙题材单人放置游戏《洞天》设计一张完整、可实际开发的高保真桌面游戏 UI 截图。固定分辨率 960×600，16:10 横屏，正面平视，像真实运行中的游戏画面，不要设备模型，不要宣传海报。

产品定位：银河奶牛式简单直接的放置玩法。玩家进入页面后，应能在 3 秒内理解当前状态和主要操作。采集、生产、修炼和战斗页面统一采用“先选择分类或区域，再点击目标项目，立即替换当前行动并开始挂机”的逻辑。不要战前确认、路线规划、队伍编成、技能配置或多步骤向导。只有突破、升级设施、淬炼等会消耗重要资源的操作允许简短确认。

所有页面共用完全相同的应用外壳：左侧 144px 固定深色导航栏，顶部显示篆刻感但清晰可读的游戏名称“洞天”，下方显示角色“云岫”和境界“炼气中期”。主导航依次为洞府、修炼、百艺、历练、角色、背包；当前页面用玉绿色竖线、浅玉底色和对应图标高亮。百艺展开时显示采药、挖矿、炼丹、炼器。底部弱化显示设置、指南、规则。市场、宗门、仙友、修行榜等联网入口不要出现。

主区域顶部固定一条 48px 高的全局挂机状态栏，所有页面位置与样式完全一致：左侧显示“正在进行：青蛇战斗”，中间是本轮细进度条和“00:18”，右侧显示累计收益“修为 +126、青蛇丹 ×3、灵石 ×18”，最右侧只有暂停图标按钮。状态栏紧凑，不做成大卡片。

视觉命题：幽深洞天中的现代修行工作台。深炭黑、墨绿和冷灰作为大面积背景，玉石青绿作为唯一主要交互色，少量暗金表示境界和稀有品质，少量朱红表示危险或资源不足。材质细节来自石壁、深色木构、青铜包边和薄雾，但信息区域保持平整清晰。不要大面积羊皮纸、米黄色、紫蓝渐变或霓虹赛博风。

使用统一的 4px 或 6px 小圆角、1px 低对比边框、克制阴影、8px 间距体系、紧凑但舒适的信息密度。页面区块尽量使用无框布局、细分隔线和列表，只在真正可点击的目标项目上使用卡片；不要卡片套卡片。中文界面，现代无衬线字体负责数据和正文，标题可带轻微宋体气质；文字完整、真实、清晰可读，不使用随机英文。

图标统一为简洁的线性东方器物图标。物品、草药、矿石、丹药、装备和怪物使用同一套写实与国风手绘结合的游戏图标，45 度柔光，深色透明底，不使用表情符号。当前选中项用玉绿描边和左侧状态线，挂机中使用细进度条和轻微呼吸光，锁定项降低亮度并显示一句明确条件。

整个页面必须完整容纳在 960×600 单屏内，无浏览器栏、无滚动条、无遮挡、无文字溢出。整体应像同一个成熟游戏设计系统生成的系列页面，而不是每页不同风格的概念稿。
```

## 1. 洞府页

```text
当前左侧导航高亮“洞府”。页面标题“洞府”，副标题“管理修行设施与长期加成”。

主工作区上方用一条紧凑摘要展示：洞府等级 Lv.4、灵气浓度 128、当前建设“炼丹炉 Lv.3 → Lv.4”、剩余 12:36。

中间横向排列三个可交互设施项目：练功房 Lv.5、炼丹炉 Lv.3、锻造炉 Lv.2。每项配一张统一风格的小型洞府室内场景缩略图，并清楚显示当前加成。当前选择“炼丹炉”，使用玉绿高亮。

下方是炼丹炉详情，左侧显示当前效果“炼丹耗时 -9%”和下一级效果“-12%”；右侧用两行展示升级成本“灵石 1,200 / 1,500、玄铁矿 18 / 20”和建造时间“15 分钟”。底部只有一个明确主按钮“升级到 Lv.4”，资源不足时按钮禁用并把缺少的 2 个玄铁矿标成朱红。

操作逻辑必须一眼可懂：点击设施查看，满足条件后点击一次升级。不要建筑摆放、自由装修、科技树、工人分配或复杂建造队列。
```

## 2. 修炼页

```text
当前左侧导航高亮“修炼”。页面标题“选择修炼方向”，右侧显示当前境界“炼气中期”和修为“4,260 / 6,000”。

主体以一列或两列紧凑目标项目展示五种真实修炼方向：练气、练剑、练刀、练枪、练杖。每项包含小型功法或武器图标、当前等级、每轮耗时、每轮修为或专精经验、对应攻击加成。练气项目显示“每轮修为 +18”；练剑显示“剑法 Lv.7，持剑攻击 +14%”。

“练气”处于挂机中，显示玉绿色状态线、细进度条和“本轮剩余 00:22”；其余项目显示“点击开始修炼”。点击任何可用项目立即开始挂机，不显示额外确认按钮。

页面右上角提供一个克制的文字入口“前往突破”，不要显示功法树、经脉棋盘、技能加点、角色打坐大插画或多层养成面板。
```

## 3. 突破页

```text
当前左侧导航仍高亮“修炼”，子导航高亮“突破”。页面标题“筑基突破”，副标题“满足条件后开始 15 分钟试炼”。

主体左侧是四条清楚的突破条件清单，每条都有状态图标、当前值和目标值：修为 6,000 / 6,000、筑基丹 1 / 1、灵石 3,000 / 3,000、洞府练功房 Lv.5 / Lv.5，全部使用完成状态。

右侧是目标境界摘要：当前“炼气大圆满”，目标“筑基初期”，成功率“100%，无随机失败”，预留材料说明保持一行。底部只有一个醒目的主按钮“确认消耗并开始试炼”。

同时在页面下方展示一个较弱的试炼状态区域，未开始时只写“尚未开始”；若生成进行中状态，则显示单一倒计时和当前节点，不要同时展示全部路线。资源消耗确认可以弹出简洁确认框，但不要老虎机式成功率、属性加点或复杂渡劫动画面板。
```

## 4. 百艺总览页

```text
当前左侧导航高亮并展开“百艺”。页面标题“百艺”，副标题“选择一门技艺开始积累材料与制品”。

主区域分成四条大型但紧凑的横向技艺入口：采药、挖矿、炼丹、炼器。每条包含统一尺寸的真实游戏图标、技能等级、经验进度、当前已解锁数量和一句用途说明。例如“采药 Lv.8，4 个区域”“炼丹 Lv.5，7 个配方”。

右侧用小型箭头表示进入，不放文字按钮。顶部挂机栏已经承担当前行动状态，因此本页不要重复放大量统计。若当前正在采药，只在“采药”入口加一个小型“进行中”标记。

页面目标是选择技艺入口，不要把四种技艺的资源、配方和升级树同时展开，也不要做成四张夸张宣传卡。
```

## 5. 采药页

```text
当前左侧“百艺”展开，子项高亮“采药”。页面标题“采药”，副标题“选择区域，点击草药开始挂机”。

第一行是横向区域选择：百草谷、雾隐坡、灵泉谷、黑风谷。每个区域带低饱和山谷缩略图、境界要求和可采草药数量；当前选中“百草谷”。

下方用三列紧凑目标项目展示青灵草、凝露花、紫叶兰。每项包含清晰草药图标、名称、每轮耗时、每轮产量、采药经验和可能的稀有额外掉落。“青灵草”处于挂机中，显示进度条；其他可用草药显示“点击开始采集”。

点击整个草药项目立即开始挂机，不放二次“开始采集”按钮。锁定草药只显示“炼气中期解锁”，不要采集小游戏、体力值、工具耐久或路线规划。
```

## 6. 挖矿页

```text
点击整个矿石项目立即开始挂机。不要矿镐操作小游戏、矿洞地图探索、采矿队伍、能源值或多层矿脉系统。
```

## 7. 炼丹页

```text
当前左侧“百艺”展开，子项高亮“炼丹”。页面标题“炼丹”，副标题“选择用途，点击丹药配方开始挂机”。

“聚气丹”处于挂机中并显示本轮进度，其余可制作配方显示“点击开始炼丹”。材料不足的配方降低亮度，并直接把缺少材料标红。点击可执行配方立即挂机，不额外弹确认。
```

## 10. 角色装备页

```text
当前左侧导航高亮“角色”。页面标题“角色”，顶部摘要显示角色“云岫”、境界“炼气中期”、战力 86、生命 420、攻击 64、防御 31。

页面采用清楚的左右布局。左侧约 38% 是低饱和修仙角色半身像，周围排列 8 个紧凑装备槽：武器、头冠、衣甲、护腕、腰带、靴子、项链、戒指。已装备物品显示真实图标和强化等级。

右侧约 62% 是装备背包，顶部使用分段控件切换武器、防具、饰品，下面是紧凑装备列表。每条显示装备图标、名称、品质、核心属性和与当前装备相比的绿色或红色差值。点击一件装备后，右侧底部出现简洁详情，并只有一个主要操作“装备”；装备后属性立即更新。
```

```text
顶部使用分段标签：游戏、通知、个人资料、聊天、账户；当前选中“游戏”。联网或账号相关标签可以显示“暂未开放”，但不展开虚构功能。

主体使用单列安静设置列表，每一行左侧为名称和一句说明，右侧为标准开关：紧凑游戏面板、减少界面动效、显示修行日志、显示时间、重要操作确认。开关打开时使用玉绿色，关闭时使用冷灰。列表下方显示一个弱化的“恢复默认设置”文字按钮。
```


## 保持同一体系的生成参数

- 尺寸固定 `960×600` 或宽高比 `16:10`。
- 所有页面使用同一个 seed；支持参考图时，将满意的历练页设为结构与风格参考。
- 结构参考权重建议高于风格自由度，风格化程度保持中等。
- 每次只生成一个页面，不要让模型在一张图里拼接多个页面。
