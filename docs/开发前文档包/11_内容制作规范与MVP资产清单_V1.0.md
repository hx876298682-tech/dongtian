# 《洞天》内容制作规范与 MVP 资产清单 V1.0

## 1. 内容目标

内容必须让同一片区域同时服务采集、战斗、目标和稀有发现，避免“第 1 关—第 2 关”式线性换皮。每条内容都要连接至少两个系统，并指向玩家下一目标。

MVP 内容分层：

- `VS`：垂直切片必须有正式规则，可使用临时美术。
- `P0`：封闭 Alpha 前必须完成。
- `Anchor`：配置和代码留扩展点，不制作完整可玩内容。

## 3. 采集行动

数值母表已提供 8 个 P0 采集种子：

### 采药

- 百草谷采药：青灵草 / 凝露花。
- 雾隐坡采药：凝露花 / 紫叶兰。
- 灵泉谷采药：紫叶兰 / 地脉参。
- 筑基药园：地脉参 / 灵髓。

### 挖矿

- 赤铜浅矿：赤铜矿 / 玄铁矿。
- 玄铁岭：玄铁矿 / 星纹钢。
- 星落矿坑：星纹钢 / 灵玉矿。
- 筑基地脉：灵玉矿 / 黑风晶。

伐灵木行动和青竹 / 铁木仍作为配方输入存在时，MVP 有两种实现选择：

1. P0 推荐：青竹 / 铁木由区域目标、普通战斗和秘境稳定供给，不开放伐灵木技能；不得依赖市场。
2. 若测试发现依赖不自然，则把青竹林作为 P1 内容加入；不得半开放一个没有成长梯度的技能。

## 5. 工具

### 药锄

木柄药锄、青铜药锄、玄铁药锄、灵玉药锄；筑基灵锄为 Anchor。

### 矿镐

木柄矿镐、青铜矿镐、玄铁矿镐、灵玉矿镐；筑基灵镐为 Anchor。

### 丹炉

粗制丹炉、青铜丹炉、玄火丹炉；筑基丹炉为 Anchor 或筑基后期扩展。

P0 正式美术至少完成 10 件工具；同类梯度保持轮廓一致，用材质和细节表达升级，不能只换边框颜色。

## 6. 装备

### 武器

- 粗制剑（VS）、青铜剑、玄铁剑、灵玉剑（P0）。
- 筑基飞剑、黑风剑（筑基 Endgame，可作为 P0 后段）；其高阶用途仍为 Anchor。

### 防具

- 布衣（VS）、青铜甲、玄铁甲、灵玉法袍（P0）。
- 筑基战甲为 Anchor / 内容扩量。

### 饰品

- 青玉佩、玄灵戒（P0）。
- 筑基护符为 Anchor / Boss 内容扩量。

每件装备需要：背包 Icon、装备槽小图、详情大图或高分辨率 Icon、来源、装备比较属性、适用 Build 标签。MVP 无需制作完整角色纸娃娃换装。

## 7. 妖兽与 Boss

数值母表已有：

| 名称 | 类型 | 区域 | 范围 |
|---|---|---|---|
| 青蛇 | 普通 | 百草谷 | VS |
| 竹叶妖 | 普通 | 雾隐丘陵 | P0 |
| 灰狼 | 普通 | 黑石坡 | P0 |
| 石甲兽 | 普通 | 玄铁岭 | P0 |
| 黑风妖狼 | 精英 | 黑风谷 | P0 |
| 灵泉守卫 | Boss / 精英 | 灵泉谷 | P0 |
| 黑风妖王 | Boss | 黑风秘境 | P0 |

为达到 8～12 种妖兽，内容制作阶段补足并进入数值母表：

- 赤铜甲虫：赤铜浅矿普通怪，提供矿区低阶掉落。
- 雾影猿：雾隐坡普通怪，提供丹药 / 工具交叉材料。
- 星纹傀：星落矿区精英，提供淬炼与星纹钢目标。

补足怪不得仅复制属性；至少在攻击节奏、补给压力或掉落需求中有一项区别。

美术需求：普通怪可用立绘 + 轻量骨骼 / 分层动效；Boss 需要独立轮廓、2～3 个关键动作和清楚的危险提示。

## 8. 秘境

| 秘境 | 目标阶段 | 节点 | 核心选择 | 核心掉落 | 范围 |
|---|---|---:|---|---|---|
| 青蛇洞 | 炼气初期 | 2 | 安全出口 / 深入巢穴 | 灵髓、青玉佩 | VS 教学 |
| 玄铁秘窟 | 炼气后期 | 3 | 矿脉 / 妖巢 | 黑风晶、玄铁剑 | P0 正式 |
| 黑风秘境 | 筑基初期 | 3 | 补给 / 高风险 Boss | 黑风晶、黑风剑 | P0 Endgame |

GDD 的“2 个秘境”最低要求由玄铁秘窟和黑风秘境承担；青蛇洞作为教学内容保留，不计正式 Endgame 数量也可以。

每个秘境资产：入口卡、节点背景 2～3 张、路线图标、核心掉落图标、Boss 表现、结果徽记、环境与战斗音效。

## 11. 音频预算

- 1 首洞府 / 首页循环音乐、1 首秘境战斗音乐、1 首突破音乐短版。
- 环境：山谷、矿洞、灵泉、黑风谷各 1 组可循环氛围。
- UI：保存、获得、稀有、失败、解锁、装备、淬炼约 10～15 个短音效。
- 战斗：剑击、受击、丹药、Boss 警示约 8～12 个。
- 音量分组：音乐、环境、战斗、UI；默认不过度打扰放置玩家。

## 12. 文案与本地化

所有内容至少有：名称、短描述、详细说明、来源、用途、锁定原因、失败原因。中文基线完成后仍使用本地化 key，不把中文作为业务逻辑键。

语气：克制、可信、带修仙感但不堆砌古文。重要规则使用现代白话；例：

> “聚气丹将在下一个完整修炼周期生效，持续 30 分钟。”

而不是模糊的：

> “服之可聚天地灵机，玄妙无穷。”

氛围文案可以保留在描述第二段。

## 13. 文件命名与交付

```text
item_qingling_herb_icon_64.png
equipment_xuantie_sword_detail_256.png
region_blackwind_valley_bg_1920.png
monster_blackwind_wolf_idle.webp
```

- 源文件与导出文件分离；源文件保留图层和字体说明。
- 透明图裁切边界一致，图标留白统一。
- 每个资产在清单中关联稳定内容 ID、负责人、状态、版本和版权来源。
- 禁止使用权属不清的网络素材进入发布包。

## 14. 单条内容 Definition of Done

- 稳定 ID、配置和本地化已提交。
- 来源、用途、解锁与目标关系完整。
- 数值母表或批准的内容配置已有数值。
- UI 正常、锁定、缺资源和获得状态可展示。
- 正式或批准的临时资产已接入，版权清楚。
- 自动化配置校验和至少一个获取 / 消耗用例通过。
- 服务端埋点和账本原因码正确。
- 内容负责人在目标境界账号上完成一次真实体验。
