## 4. 冲突审计

已处理的潜在冲突：

- GDD V0.1 表格曾把条件队列写到金丹，后续确认和数值母表统一为筑基开放；本包全部按筑基执行。
- 秘境不是每日重置；统一为 12 小时自然累计、上限 6，封顶时间不储存。
- 普通生产当前周期采用“预留输入，完成时永久消耗”，解决取消、并发资产消耗和负库存问题。
- 突破不是一次即时扣料按钮；统一为资产预留、15 分钟试炼、完成事务和断线恢复。
- 奖励在服务端结算时直接入账；UI 结果页不是资产领取开关。
- 伐灵木不属于 MVP 百艺；青竹 / 铁木首版通过区域目标、普通战斗和秘境供给，若验证不自然再完整加入该技能。

未发现以下相互冲突口径：境界范围、队列槽位、药力槽、离线容量、秘境并发、市场延后、突破目标日和主动价值区间。

现在可以开始：

1. M0 仓库、环境、数据库、配置 Schema、CI 和可观测性。
